# Streamlabs Desktop вместо OBS Studio

> English version: [STREAMLABS.md](STREAMLABS.md)

Шлюзу всё равно, какая программа показывает картинку. Он отдаёт поток PS5 по одному фиксированному адресу, `rtmp://<ваш ПК или Mac>:1935/ps5/game`, и прочитать его может любая программа, умеющая открывать RTMP-адрес. Streamlabs Desktop построен на том же ядре, что и OBS Studio, и у него такой же источник, который Streamlabs называет **Media File** (в OBS он называется Media Source), так что настройка по сути та же.

**Статус.** Шлюз проверен с OBS Studio на настоящем железе. Проверено автором в Streamlabs Desktop 1.21.6 на macOS тестовым потоком: источник **Media File** с RTMP-адресом шлюза добавляется, картинка и звук приходят. Окно настроек и Fit to Screen ниже описаны так, как они выглядят там. Пока не проверено: настоящая трансляция PS5 в Streamlabs и Windows. Если пункт меню или настройка выглядит иначе, напишите в [issue](https://github.com/avedevelop/ps5-gateway/issues), что видите. Streamlabs Desktop есть и для macOS, шаги те же.

## 1. Установите шлюз

Используйте установщик в один клик ([INSTALL.ru.md](INSTALL.ru.md)). Шаг установщика про сцену OBS относится только к OBS Studio, поэтому его пропустите: добавьте `-NoScenes` на Windows или `--no-scenes` на macOS, либо проигнорируйте его сообщение. В конце установщик покажет адрес вашего компьютера (например, `192.168.1.20`) и что указать на PS5 (DNS). Точный адрес для плеера есть и на панели <http://127.0.0.1:8787>.

## 2. Добавьте источник PS5 в Streamlabs Desktop

1. Создайте сцену, например **PS5**.
2. В **Источниках** нажмите **+**. В окне Add Source введите в поиске `Media File` (по запросу «media source» ничего не находится: Streamlabs называет этот источник **Media File**; входить в аккаунт для этого не нужно), выберите **Media File**, нажмите Add Source и назовите `PS5`.
3. Снимите галочку **Local File** (локальный файл).
4. В поле **Input** впишите `rtmp://<адрес вашего компьютера>:1935/ps5/game`.
5. Поставьте **Reconnect Delay** равным **2** (по умолчанию 10): источник сам повторяет попытки, и с короткой задержкой картинка появляется через несколько секунд после старта PS5. Снимите галочку **Restart playback when source becomes active** (по умолчанию она стоит), чтобы переключение сцен не перезапускало подключение, а **Close file when inactive** оставьте выключенной.
6. **Network Buffering** оставьте 2, а **Use hardware decoding when available** выключенным (это значения по умолчанию). Нажмите **Close**. Источник переподключается сам, поэтому Streamlabs можно запускать до PS5.
7. Если картинка чёрная при идущей трансляции PS5, откройте свойства источника (правый клик, **Properties**) и переключите **Use hardware decoding when available**.

## 3. Растяните картинку на весь экран

- В **Settings > Video** задайте **Base (Canvas) Resolution** и **Output (Scaled) Resolution** равными **1920x1080**. На MacBook холст по умолчанию повторяет форму экрана (16:10) и обрезает картинку по бокам.
- Правый клик по источнику PS5, **Transform > Fit to Screen**. Делайте это после смены холста: до этого картинка остаётся своего размера (например, 1280x720) в левом верхнем углу.

## 4. Выход в эфир

1. На PS5: укажите DNS своего компьютера (см. [INSTALL.ru.md](INSTALL.ru.md)), откройте «Трансляция», выберите Twitch, Go Live. Источник PS5 в Streamlabs покажет игру.
2. В Streamlabs подключите аккаунт Twitch (или ключ трансляции) и нажмите **Go Live**, когда будете готовы. До этого момента в Twitch ничего не уходит.
3. Оверлеи, алерты и виджеты Streamlabs работают как обычно: это обычные источники поверх сцены с PS5.

## Необязательно: сцена из OBS

`node scripts/make-obs-scenes.mjs` создаёт коллекцию сцен для OBS Studio. В Streamlabs Desktop в окне коллекций сцен есть кнопка **Import**, которая умеет читать коллекции OBS Studio; если у вас она сработает, источник придёт уже растянутым. Мы это не проверяли, а ручная настройка занимает минуту, поэтому надёжнее она.

## Другие программы

Подойдёт всё, что открывает RTMP-адрес: вставьте `rtmp://<компьютер>:1935/ps5/game` как сетевой или медиа-источник. Например, Meld Studio, vMix, VLC (чтобы просто посмотреть картинку: File > Open Network).
